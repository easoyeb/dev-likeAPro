# 📱 Android Development Course: From Beginner to Pro

Welcome to the hands-on Android Development course! This course is designed to take you from foundational concepts to reverse-engineering real production codebases (like **mpvRex**).

---

## 🗺️ Course Curriculum Roadmap



1. **[Lesson 1: The Kotlin Decoder](./kotlin-decoder)** — Demystify Kotlin symbols (`?`, `::`, `@`, `by`) & Custom vs Library classes.
2. **[Lesson 2: Universal Code Navigation](./codebase-navigation)** — The 3 Universal Anchors to locate any feature in any Android app in 60s.
3. **[Lesson 3: The Feature Lifecycle](./feature-lifecycle)** — The 6-step feature addition pipeline and surgical deletion checklist.
4. **[Module 1: Compose Fundamentals](./module1-basics)** — Activities, Composables, Layouts & Modifiers.
5. **[Module 2: State & Storage](./module2-state-management)** — StateFlow, Preferences, and Koin Dependency Injection.
6. **[Module 3: Custom UI & Canvas](./module3-custom-ui-canvas)** — Drawing custom Seekbars and Canvas graphics.
7. **[Module 4: Reading Codebases](./module4-how-to-read-codebases)** — Reverse-engineering real production apps.
